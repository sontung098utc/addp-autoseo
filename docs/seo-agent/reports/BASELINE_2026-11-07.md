## Cách tái lập
```bash
git worktree add ../wt-baseline --detach origin/develop && cd ../wt-baseline
cp .env.example .env
docker build -t addp-autoseo-app:webp-check .
docker run --rm -e APP_KEY="base64:$(openssl rand -base64 32)" -e APP_ENV=testing \
  -v "$PWD":/var/www/html -v <đường-dẫn-vendor>:/var/www/html/vendor -w /var/www/html \
  addp-autoseo-app:webp-check php artisan test
```
